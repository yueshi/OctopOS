# 项目报告台账 · 使用说明

## 它是什么

把项目经理手里的同格式周报/日报 Excel，汇总成一个可查询、可对比、可分享的任务台账。
项目是台账里的一列；每个报告期是一批任务快照；原始 Excel 保留在工作区。

## 第一次使用

1. 在专家库创建「项目台账助手」。
2. 对话里点「初始化台账」，或说“初始化项目报告台账”。
3. 把本周 Excel 放进 `reports/`，或直接在对话里上传。
4. 说“导入本期报告”。助手会先预检，再入库。

## 文件命名

推荐：

```text
reports/A项目-2026-W46.xlsx
reports/B项目-2026-W46.xlsx
```

也支持一个文件包含多个项目：文件里必须有「项目」「周期」列。

## 报告里建议有的列

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 项目 | 文件名有可省略 | 一个文件多个项目时必填 |
| 周期 | 文件名有可省略 | `2026-W46` / `2026-11-19` / `2026-11` |
| 任务编号 | 建议 | 没有时用“项目+任务名”代替；改名会被当成新任务 |
| 任务名称 | 是 | |
| 负责人 | 否 | |
| 状态 | 建议 | 未开始/进行中/阻塞/已完成，或自定义同义词 |
| 进度 | 否 | 百分比或 0–1 小数 |
| 优先级 | 否 | 低/中/高 |
| 开始日期、截止日期 | 否 | 日期格式 |
| 备注 | 否 | 长文本 |

合计/小计行会自动跳过；身份证、银行卡、手机号、薪资列默认不导入。

## 查看方式

- **本期任务**：默认最新报告期，按项目/状态/负责人筛选。
- **项目总览**：每个项目的任务数、完成率、延期、阻塞、平均进度；
  如果「项目档案」表有该项目，会显示项目正式名称、负责人和项目状态。
- **历史报告**：每个报告期、来源文件、导入时间和行数。
- **风险清单**：延期或阻塞的任务，按逾期天数排序。
- 点任务可以看它的跨期轨迹和来源文件。

## 项目档案（可选）

「项目档案」表用来存项目正式名称、负责人、项目状态和起止日期。它不参与导入；
可以手工维护，或让助手导入一份 `project,project_name,owner,status` 的 CSV。
表里没有的项目，页面直接用周报里的 `project` 值显示。

## 升级

已有台账需要补「项目档案」表、追加新列或换最新界面时，对助手说“升级台账”。
助手会先检查现状，只补缺失的表/列，并在覆盖界面前确认；不会删除数据。

## 归档

1. 在应用详情页下载主表 CSV 和一次应用备份，放到 `reports/archive/`。
2. 对助手说“归档 2025 年及以前，保留 2026 年”。
3. 助手运行 `archive.py`，输出 `tasks_retained.csv` / `tasks_archived.csv` / `archive_summary.json`。
4. 只归档不清理时到此结束；要清理活动表时，确认 dry-run 行数后再执行 replace。

原始 Excel 和导出文件都不会被删除。

## 分享

- 应用详情页创建只读公开链接；公开页只展示任务明细，不展示来源文件和导入记录。
- **任务备注属于主表，公开链接会一并返回**；发布前确认备注里没有内部信息，或先把敏感内容移出备注。
- 分享前确认受众；公开链接是 bearer token 语义。

## 常见问题

**导入后数字不对？** 先看导入记录的失败摘要，再检查 Excel 的表头、状态词、日期格式。
**同一份文件重复导入？** 助手会按文件 hash 跳过；需要覆盖时明确说“重导这一期”。
**任务改名后出现两条？** 说明没有稳定任务编号；建议在 Excel 里补编号。
**历史报告能改吗？** 默认只读；修正某期时只重导该期，不影响其它期。

## 边界

- 不做审批流，不做多页面 HTML，不做跨应用共享表。
- 单表上限 2 万行；部门级数据建议按年归档（见「归档」）。
- 页面只读；修改任务请改源 Excel 后重导该报告期。
- 导入脚本需要 `local_shell` / `filesystem` 后端；纯远程对象存储后端暂不能直接运行脚本。
